**Problem :**
Given an array, find the minimum absolute difference between any two elements.

*Example*
INPUT:[5,1,9,3]
OUTPUT: 2
 **Approach 1** 
 Brute force:
 Compare every pair.
 Time complexity: O(n^2)
**Approach 2**
Sort the array
The minimum absolute difference must occur between adjacent elements.
Time complexity: O(n log n)
